# Shrek-LMS 역할별 수동 QA 체크리스트

## 1. 목적

이 문서는 Shrek-LMS의 로그인, 역할별 이동, 주요 목록/상세 화면, 빈 상태, 예외 안내, 로그아웃 흐름을 수동으로 점검하기 위한 체크리스트입니다.

---

## 2. 사전 준비

- [ ] `.env.local` 파일이 존재하고 최신 설정이 반영되어 있다.
- [ ] `NEXT_PUBLIC_SUPABASE_URL`이 설정되어 있다.
- [ ] `NEXT_PUBLIC_SUPABASE_ANON_KEY`가 설정되어 있다.
- [ ] 개발 서버가 실행 중이다 (`npm run dev`).
- [ ] 테스트 계정이 준비되어 있다.
- [ ] `admin` / `teacher` / `student` / `parent` 역할 계정이 준비되어 있다.
- [ ] `npm run build`가 통과한다.

---

## 3. 공통 접속 흐름 체크

- [ ] `http://localhost:3000/` 접속 시 `/login`으로 이동한다.
- [ ] `/login` 화면 서비스명이 `슈렉샘 논술 LMS`로 표시된다.
- [ ] 이메일/비밀번호 입력창이 정상 표시된다.
- [ ] 잘못된 로그인 정보 입력 시 화면이 깨지지 않는다.
- [ ] 정상 로그인 시 역할별 화면으로 이동한다.
- [ ] 로그아웃 버튼이 정상 동작한다.
- [ ] 로그아웃 후 보호 화면 접근 시 로그인 화면으로 이동한다.

---

## 4. role 없음 또는 role 조회 실패 체크

- [ ] role이 없는 계정으로 로그인 시 `/dashboard` 안내 화면이 표시된다.
- [ ] "역할 확인이 필요합니다" 의미의 안내가 명확하게 보인다.
- [ ] 관리자에게 역할 설정을 요청하라는 문구가 표시된다.
- [ ] 안내 화면의 로그아웃 버튼이 정상 동작한다.

---

## 5. 관리자 화면 체크

- [ ] admin 계정으로 로그인한다.
- [ ] `/admin/dashboard`에 진입한다.
- [ ] 관리자 대시보드 화면이 정상 표시된다.
- [ ] 반 목록 화면이 정상 표시된다.
- [ ] 학생 목록 화면이 정상 표시된다.
- [ ] 교사 목록 화면이 정상 표시된다.
- [ ] 데이터가 없을 때 빈 상태 안내 문구가 표시된다.
- [ ] 기존 카드/목록 구조가 깨지지 않는다.
- [ ] 로그아웃이 정상 동작한다.

---

## 6. 교사 화면 체크

- [ ] teacher 계정으로 로그인한다.
- [ ] 교사 첫 화면에 진입한다.
- [ ] 과제 목록 화면이 정상 표시된다.
- [ ] 과제 등록 화면이 정상 표시된다.
- [ ] 제출함 화면이 정상 표시된다.
- [ ] 제출 상세/첨삭 상세 화면이 정상 표시된다.
- [ ] 제출물이 없을 때 안내 문구가 표시된다.
- [ ] 제출 답안이 없을 때 fallback 문구가 표시된다.
- [ ] 첨부 파일이 없을 때 fallback 문구가 표시된다.
- [ ] 첨삭 코멘트/점수가 없을 때 fallback 문구가 표시된다.
- [ ] 잘못된 제출 id로 접근해도 사용자 친화적인 안내(또는 차단 화면)가 표시된다.
- [ ] 로그아웃이 정상 동작한다.

---

## 7. 학생 화면 체크

- [ ] student 계정으로 로그인한다.
- [ ] 학생 홈에 진입한다.
- [ ] 강의 목록 화면이 정상 표시된다.
- [ ] 과제 목록 화면이 정상 표시된다.
- [ ] 과제 상세 화면이 정상 표시된다.
- [ ] 과제 제출 화면이 정상 표시된다.
- [ ] 제출 이력 영역이 정상 표시된다.
- [ ] 미제출 상태 안내 문구가 표시된다.
- [ ] 제출 기록은 있으나 내용이 비어 있을 때 안내 문구가 표시된다.
- [ ] 첨삭 목록 화면이 정상 표시된다.
- [ ] 첨삭 상세 화면이 정상 표시된다.
- [ ] 첨삭 코멘트/점수/제출 답안 누락 시 fallback 문구가 표시된다.
- [ ] 포트폴리오/성장 화면이 정상 표시된다.
- [ ] 잘못된 과제 id 또는 첨삭 id로 접근해도 안내(또는 차단 화면)가 표시된다.
- [ ] 하단 탭 active 상태가 자연스럽다.
- [ ] 로그아웃이 정상 동작한다.

---

## 8. 학부모 화면 체크

- [ ] parent 계정으로 로그인한다.
- [ ] 학부모 첫 화면에 진입한다.
- [ ] 자녀 과제 현황 화면이 정상 표시된다.
- [ ] 첨삭 목록 화면이 정상 표시된다.
- [ ] 첨삭 상세 화면이 정상 표시된다.
- [ ] 자녀 답안 텍스트 없음 fallback 문구가 표시된다.
- [ ] 첨삭 상세 데이터 부족 시 안내 문구가 표시된다.
- [ ] 코멘트 없음 문구가 표시된다.
- [ ] 제출 답안 없음 문구가 표시된다.
- [ ] 잘못된 첨삭 id로 접근해도 안내(또는 차단 화면)가 표시된다.
- [ ] 로그아웃이 정상 동작한다.

---

## 9. 권한/직접 URL 접근 체크

- [ ] 학생이 다른 학생의 과제/첨삭 상세 URL에 접근했을 때 차단 또는 안내된다.
- [ ] 학부모가 연결되지 않은 학생의 첨삭 URL에 접근했을 때 차단 또는 안내된다.
- [ ] 교사가 담당하지 않는 제출물 URL에 접근했을 때 차단 또는 안내된다.
- [ ] 로그아웃 상태에서 보호 라우트 접근 시 `/login`으로 이동한다.
