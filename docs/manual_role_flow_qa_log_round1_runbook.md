## 8) 실행 후 문서 반영 절차

1. 이 런북의 결과를 `docs/manual_role_flow_qa_log_round1.md` 동일 항목에 반영합니다.
2. `FAIL` 항목은 `docs/manual_role_flow_qa_log_round1.md`의 "발견 이슈 목록"에 번호를 맞춰 복사합니다.
3. `BLOCKED` 항목은 메모에 실행 불가 사유(계정 없음, 데이터 없음, 환경 문제)를 구체적으로 남깁니다.
4. 최종 결과(`PASS/FAIL/BLOCKED`)를 로그 문서의 "Round 1 결론"에 확정합니다.
5. 후속 수정이 필요하면 수정 요청 본문에 아래 3가지를 함께 첨부합니다.
   - 실패 항목 번호
   - 재현 경로(URL/역할)
   - 기대 결과 vs 실제 결과
