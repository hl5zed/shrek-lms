# prd.md — 논술마루 LMS 제품 기획 문서

---

## 서비스 개요

- 서비스명: 논술마루 LMS
- 목적: 학생의 논술 글쓰기 과정을 기록하고, 강사의 첨삭·평가를 체계화하며, 학부모에게 성장 리포트를 제공하는 학원 관리 시스템
- 핵심 사용자: 관리자 / 강사 / 학생 / 학부모

---

## MVP 범위 (Phase 0~4 완성 목표)

MVP는 아래 핵심 흐름 하나가 완전히 작동하는 것을 목표로 합니다.

> **학생이 과제를 제출하고 → 강사가 첨삭하고 → 학생과 학부모가 결과를 확인한다**

### MVP 포함 기능

| 번호 | 기능 | 비고 |
|------|------|------|
| 1 | 이메일/비밀번호 로그인 | 역할별 페이지 분기 |
| 2 | 학생 등록 및 학부모 연결 | 관리자가 처리 |
| 3 | 반 생성 및 학생 배정 | 관리자/강사가 처리 |
| 4 | 강의 등록 | 제목·설명·영상URL·자료파일·대상 반 |
| 5 | 과제 등록 | 제목·설명·마감일·대상 반 |
| 6 | 학생 과제 제출 | 텍스트 입력·이미지 업로드·PDF 업로드 |
| 7 | 글자 수 카운트 | 실시간 카운트 (공백 포함/제외) |
| 8 | 강사 첨삭 | 종합 코멘트·영역별 코멘트·첨삭 상태 |
| 9 | 성장지표 입력 | 독해력·사고력·논리력·구성력·표현력 (1~5점) |
| 10 | 학부모 화면 | 과제 제출 상태·첨삭 결과·주간 요약 |
| 11 | 관리자 대시보드 | 전체 학생·강사·반 관리 |
| 12 | 강사 대시보드 | 제출 대기·첨삭 대기·미제출 학생 확인 |

### MVP 제외 기능 (나중에 추가)

- AI 첨삭 보조
- 태블릿 이미지 드로잉 첨삭
- 음성 첨삭
- 결제/수강권 관리
- 카카오 알림톡
- 지점(멀티 학원) 관리
- 포트폴리오 PDF 출력
- 고급 영상 보안

## 역할별 핵심 화면

### 관리자 (admin)
- 전체 대시보드 (학생 수·강사 수·반 수·첨삭 현황)
- 강사 계정 생성·관리
- 학생 등록·학부모 연결·반 배정
- 반 생성·수정

### 강사 (teacher)
- 대시보드 (첨삭 대기·제출 대기·미제출 학생)
- 강의 등록·관리
- 과제 등록·관리
- 제출함 (학생 제출물 목록)
- 첨삭 작성 화면

### 학생 (student)
- 내 강의 목록
- 내 과제 목록 (제출 상태 포함)
- 과제 제출 화면 (텍스트·파일·글자수)
- 첨삭 결과 확인
- 성장 지표 확인

### 학부모 (parent)
- 자녀 과제 제출 현황
- 자녀 첨삭 결과
- 자녀 성장 추이

## 기술 방향

- 영상: 자체 업로드 없이 YouTube / Vimeo / Bunny Stream URL 등록
- 파일: Supabase Storage (이미지·PDF)
- 인증: Supabase Auth (이메일/비밀번호)
- 권한: Supabase RLS (Row Level Security)
- 배포: Vercel (GitHub 자동 배포)
