---

## 역할 정의

| 역할 | role 값 | 설명 |
|------|---------|------|
| 관리자 | admin | 전체 시스템 관리. 강사·학생 계정 생성, 반 구성, 전체 데이터 열람 |
| 강사 | teacher | 배정된 반의 강의·과제 관리, 제출물 조회, 첨삭 작성 |
| 학생 | student | 본인 과제 확인·제출, 본인 첨삭 결과·성장지표 확인 |
| 학부모 | parent | 연결된 자녀의 과제 현황·첨삭 결과·성장 추이 열람 (읽기 전용) |

## 라우팅 보호 규칙

```
/admin/*       → admin만 접근
/teacher/*     → teacher만 접근
/student/*     → student만 접근
/parent/*      → parent만 접근
/login         → 비로그인 사용자만 접근 (로그인 시 역할별 페이지로 리다이렉트)
```

### 로그인 후 리다이렉트

```
admin   → /admin/dashboard
teacher → /teacher/dashboard
student → /student/dashboard
parent  → /parent/dashboard
```

### 미들웨어 처리 원칙

- 비로그인 사용자가 보호 페이지 접근 시 → /login으로 리다이렉트
- 로그인 사용자가 다른 역할의 페이지 접근 시 → 본인 역할 대시보드로 리다이렉트
- profiles 테이블에서 role 확인 (auth.users의 메타데이터가 아닌 profiles 기준)

## 데이터 접근 범위 요약

### 관리자 (admin)
- 모든 테이블 전체 행 조회·수정 가능
- 유일하게 profiles의 role을 변경할 수 있음
- 유일하게 다른 사용자 계정을 생성·관리할 수 있음

### 강사 (teacher)
- classes: 본인이 teacher_id인 반만 조회
- class_students: 본인 반의 학생만 조회
- assignments: 본인 반의 과제만 생성·수정·조회
- lectures: 본인 반의 강의만 생성·수정·조회
- submissions: 본인 반 학생의 제출물만 조회
- feedbacks: 본인이 작성한 첨삭만 생성·수정

### 학생 (student)
- class_students: 본인이 속한 반 정보만 조회
- assignments: 본인 반에 등록된 과제만 조회
- lectures: 본인 반에 등록된 강의만 조회
- submissions: 본인 제출물만 생성·조회·수정 (reviewed 상태 이후 수정 불가)
- feedbacks: 본인 제출물에 대한 첨삭만 조회 (작성 불가)

### 학부모 (parent)
- parent_students: 본인과 연결된 자녀 목록 조회
- submissions: 자녀의 제출물만 조회 (수정 불가)
- feedbacks: 자녀의 첨삭 결과만 조회 (수정 불가)
- assignments: 자녀 반의 과제 목록만 조회 (수정 불가)
